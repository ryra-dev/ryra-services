Grafana runs behind the Ryra web contract with a loopback backend and hourly encrypted backups by default.

Set `auth.mode = "none"` for native login, even when the shared Authelia/LLDAP provider is enabled. The initial administrator is `admin`; its generated password lives in `grafana-adminpass`. For custom authentication, select `none` and supply Grafana settings through `settings.extraSettings`, using runtime file providers for secrets. Anonymous access remains disabled.

Shared OIDC uses PKCE and the canonical web origin. Private OIDC needs `web.externalUrl`, a stable HTTPS origin. New users receive Viewer. Set `settings.allowedGroups` to restrict admission, `settings.roleAttributePath` to an explicit JMESPath role policy, and `settings.allowAssignGrafanaAdmin = true` only when that policy deliberately grants server administration. For example, `contains(groups, 'grafana-editors') && 'Editor' || 'Viewer'` grants editor access to that group.

Backups stop Grafana, create and validate a SQLite snapshot, capture the data and plugins, then restart Grafana, including after backup failure. Restore stops Grafana, restores the files, validates the snapshot, replaces the database and checks application health. A failed restore requires correcting the failure before resuming work. Retain the original `grafana-secret-key` and declaration with the backup: encrypted datasource credentials need that key. Restore using the matching Grafana version first.

Use `sudo ryra-backup-grafana backup`, `snapshots`, and `restore SNAPSHOT`. A restore replaces saved content and should be rehearsed on an isolated machine. Validate a saved dashboard, datasource and login after restore before relying on the backup.

Run `nix eval --json --impure --file services/grafana/check.nix` for the auth and contract evaluation. On a disposable native-auth fixture with curl, jq and socat, run `RYRA_GRAFANA_RESTORE_FIXTURE=1 bash services/grafana/restore-smoke.sh APP_URL ADMIN_JSON` as root. The JSON file contains `username` and `password`. This creates saved content, backs up, mutates it, restores the actual repository snapshot and verifies native login, dashboard, decrypted datasource credentials and plugin data. Its local backend on port 19090 accepts only the saved secret header. Shared OIDC uses the Grafana branch of `scripts/auth-smoke.sh` with a Viewer fixture account.
